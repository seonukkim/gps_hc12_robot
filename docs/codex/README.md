# Codex Documentation

This area is only for reusable Codex-related documentation that may help future
work on the project.

Do not store temporary task prompts, one-off task logs, copied chat transcripts,
or legacy `codex_task*.md` files in the repository. Do not create
`docs/codex/tasks/` for temporary work.

One-off Codex prompts should be pasted directly into the Codex session or saved
outside the repository, for example under `/tmp`, when a short-lived working
file is useful.

Legacy `codex_task*.md` files were cleaned up from the repository. Do not
recreate them.

Reusable future prompt templates live in `docs/codex/prompts/`. A prompt belongs
there only when it is intended to be reused across future project work by
replacing variables such as hardware status, report section, file path, or test
target.

Project audit, cleanup, and validation notes belong under `docs/project_notes/`.
