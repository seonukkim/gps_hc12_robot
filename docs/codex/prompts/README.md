# Reusable Prompt Templates

This directory is reserved for reusable future prompt templates only.

A prompt belongs here only if it is intended to be reused across future project work by replacing variables such as hardware status, report section, file path, or test target. One-off task requests, temporary Codex logs, and legacy `codex_task*.md` files do not belong here.

Recommended template content:

- Purpose and expected output.
- Required project context.
- Replaceable variables.
- Safety constraints, including safe station defaults and wheel-off-ground motor testing.
- Explicit warnings not to claim ROS2 or HC-12 integration as complete unless verified.
