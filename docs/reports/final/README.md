# Final Report Workspace

Use this directory for final report material after interim report content has been reviewed and verified.

Final-report claims should reflect verified project state. Do not describe ROS2 behavior, HC-12 station integration, magnetic adhesion, or complete cleaning/painting operation as finished unless those items have been implemented and tested.

## Evidence Standard

Include only material that can be traced back to one of these sources:

- Project code, tests, scripts, or generated outputs.
- Hardware bring-up notes and captured evidence.
- Course-provided requirements or instructor guidance.
- External references with source and license notes.

## Layout

- `figures/generated/`: final figures generated from project data, scripts, mock missions, diagrams, or processed logs.
- `figures/raw/`: original source captures before cropping, annotation, resizing, or cleanup.
- `figures/external/`: sourced reference figures that are not produced by this project.
- `tables/`: final tables and their source files.

Keep temporary prompts and one-off Codex task material outside the repository. Reusable future prompt templates belong under `docs/codex/prompts/`.
